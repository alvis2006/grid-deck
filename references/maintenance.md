# 維護與回歸測試

本次優化維持 Claude 用的技能封裝與既有資料格式。

## 修正項目

- 版本檔名加上 UUID；快速連續存同名版本不再互相覆蓋。還原前仍會自動備份。
- 原子存檔使用唯一暫存檔，成功或失敗後清理暫存檔。
- GET 立即偵測外部改動並更新修訂號，防止讀取操作吞掉通知。
- 編輯器存檔、確認階段及還原版本後通知其他視窗；拒絕舊修訂覆蓋。
- 未儲存或有衝突時停止確認版本、還原及匯出；有待同步的資料時優先同步。
- 缺少／錯誤的 slides、頁面、元素、動畫資料改為報告錯誤；檢查動畫時間與圖表數字。
- HTML 匯出拒絕未知格式，素材或腳本不允許讀取簡報目錄外的檔案（含符號連結）。缺檔會明確報錯。
- 本機服務拒絕不同來源的瀏覽器請求；關閉服務後清理檔案監看與事件連線。
- Claude 說明補上遠端環境限制、共同編輯、離線圖片及視覺驗證原則。

## 驗證

在技能根目錄執行：

```bash
node --test tests/regression.test.mjs
```

測試會在系統暫存目錄建立及清理獨立測試簡報；可用 `GD_TEST_TMP` 指定可寫入的測試父目錄。服務測試只連線 127.0.0.1，不需要外網。

5 組測試覆蓋：30 次連續同名備份與還原、錯誤結構、跨目錄素材與無效匯出格式、中文 HTML 雙畫面匯出，以及服務的同步通知／修訂衝突／請求來源檢查。

這些測試不涵蓋拖曳操作、動畫視覺呈現及實際 PDF 列印；更動這些功能後仍需開啟編輯器並逐頁查看截圖。

## 編輯器介面更新

新增工作區面板切換、專注畫布、縮放比例顯示與 ResizeObserver 自動適合。工具列支援換行；窄螢幕側欄改為可收合浮層。補上模式選取語意、按鈕名稱、儲存狀態朗讀、鍵盤焦點及減少動態效果設定。

本次通過 JavaScript 語法與既有 5 組回歸測試；尚未完成瀏覽器畫面與實際點擊驗證。

## 五階段流程更新

改為確認大綱、確認排版樣稿、製作與確認完整靜態稿、製作與確認動態效果、最終導出。大綱與樣稿由 Claude 在對話中提交確認；編輯器按鈕「確認靜態稿」對應第三階段，仍使用相容的 static-confirmed 值。「確認動畫」對應第四階段。不新增自動強制關卡；使用者可明確授權合併階段。

## 動畫工作台試用版

新增 workbench.html、workbench.css、workbench.js，以原有 API 讀取及手動保存動畫。使用原有播放引擎整頁預覽；一般入場效果支援時間軸局部預覽。

已以 Edge 無頭瀏覽器實測頁面載入、元素選取、時長修改、播放進度、時間滑桿、檔案儲存、復原及整頁預覽，確認 1440px 與 760px 寬度無橫向溢出、無未捕捉瀏覽器例外；既有 5 組回歸測試通過。拖曳時間條已實作，尚未加入自動化指標拖曳測試。

## 文字框與右鍵選單

文字輸入、貼上、文字樣式變更及縮窄框時自動增加框高，保留寬度與位置；輸入內容和高度同步保存。已在瀏覽器驗證即時增高、保留編輯 DOM、存檔、文字與高度一起復原，以及字級增加後容納文字。

畫布右鍵新增元素操作與空白畫布選單，保留多選、文字編輯原生選單，支援方向鍵選項與 Esc 關閉。已測試選單不超出畫面、建立副本及復原、空白處選單與 Esc 關閉。
